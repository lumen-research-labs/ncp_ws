kills the robot, restarts slam_toolbox with an empty map anchored on the odometry frame, re-fixes the policy goal from the goal x / y fields. Use after the robot was carried.
map → odom IS the correction: how far SLAM has moved the odometry's idea of where the robot is. It should GROW as you drive — /odom over-reads by ~5%. Staying at exactly zero while driving means scan matching is contributing nothing. Each loop closure steps the pose and resets the policy's recurrent state. SLAM input zeros must be 0: the TG30's no-return sentinel is 0.0 and karto reads it as a hit at the sensor.

Controls

command source
roam —
Changing the source force-kills, so arming is always a separate act. A policy button is greyed until its node is publishing. Goals go to every running policy, so the one you switch to is already aimed. Re-targeting also resets each CfC's recurrent state. ROAM makes every running policy draw its own next goal on arrival or timeout (config/roam.yaml); off keeps the current goal and does not stop the robot.

Manual drive — hold to move

60% idle
WASD or arrow keys — hold to drive, release to stop. Space stops. Needs command_source: teleop and the robot ARMED. Each press is only valid for a moment: the browser re-sends while you hold, and the robot stops on its own if this page closes or the network drops.

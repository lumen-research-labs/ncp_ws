map → odom IS the correction: how far SLAM has moved the odometry's idea of where the robot is. It should GROW as you drive — /odom over-reads by ~5%. Staying at exactly zero while driving means scan matching is contributing nothing. Each loop closure steps the pose and resets the policy's recurrent state. SLAM input zeros must be 0: the TG30's no-return sentinel is 0.0 and karto reads it as a hit at the sensor.
